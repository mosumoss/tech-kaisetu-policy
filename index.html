tech-kaisetu uploader

「AIに言われた言葉」解説ショートの運営者が、自分の動画を自分の YouTube チャンネルと TikTok アカウントに投稿するためだけに使う、個人用のツールです。一般には提供していません。

プライバシーポリシー

このツールは、運営者自身の Google アカウントと TikTok アカウントでのみ認可して使います。

  • 使う権限: YouTube への動画のアップロード（youtube.upload）と、投稿先チャンネルの確認・投稿内容の読み戻し（youtube.readonly）。
  • TikTok で使う権限: 基本的なアカウント情報（user.info.basic）と、動画を下書きとして受信箱へ送ること（video.upload）。公開は運営者が TikTok アプリで行います。
  • 扱うデータ: 運営者のチャンネル ID・アカウント ID と、運営者が投稿した動画の情報だけです。他の人のデータは集めません。
  • 保存場所: 認可のトークンは運営者の手元のコンピュータにだけ保存し、第三者に提供・販売しません。
  • 取り消し: Google アカウントの「サードパーティ製のアプリとサービス」、TikTok アプリの「設定とプライバシー」→「セキュリティ」→「アプリの権限」からいつでも取り消せます。

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
